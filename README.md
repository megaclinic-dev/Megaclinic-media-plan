# Media Plan · ตารางช่องทาง

ระบบวางแผนงานคอนเทนต์สำหรับทีมครีเอทีฟของคลินิกความงาม — ล็อกอินรายบุคคล, สิทธิ์ตามตำแหน่ง,
ตารางแผนงาน (ช่องทาง × วัน), ปฏิทินคอนเทนต์, หน้าสรุป, ตั้งค่ามาสเตอร์ดาต้า,
ประวัติการแก้ไข และ export Excel / CSV / JSON — UI ภาษาไทยทั้งหมด

## เปิดใช้งาน
เป็นเว็บ static ล้วน เปิดได้เลยโดยไม่ต้อง build:

- เปิดไฟล์ `index.html` ผ่าน static server (หรือ deploy โฟลเดอร์นี้ทั้งก้อน)
- ล็อกอิน: เลือกผู้ใช้คนแรก รหัสผ่านเริ่มต้น `1234` (เปลี่ยนได้ที่เมนู "ทีมงาน")

`media-plan.artifact.html` = เวอร์ชันไฟล์เดียว (bundle React + โค้ดทั้งหมดไว้ในไฟล์เดียว) เปิดได้ทันทีแบบ offline

## Deploy
- **GitHub Pages** — เปิด Settings → Pages → Deploy from branch: `main` / root แล้วเว็บจะขึ้นที่ `https://<user>.github.io/<repo>/`
- **Netlify** — มี `netlify.toml` (publish = `.`) พร้อม deploy ได้เลย

## ข้อมูลกลาง (Supabase)
`index.html` ต่อกับ **Supabase** เป็นฐานข้อมูลกลาง — ทุกคนในทีมเห็นข้อมูลชุดเดียวกัน และ **sync เรียลไทม์** (แก้ที่เครื่องหนึ่ง เครื่องอื่นเห็นทันที)
- เก็บ state ทั้งก้อนไว้ในตาราง `app_state` (แถวเดียว, คอลัมน์ `data` เป็น jsonb)
- ยัง cache ลง `localStorage` ด้วย เพื่อเปิดเร็ว/ใช้ต่อได้ชั่วคราวถ้าเน็ตหลุด
- `media-plan.artifact.html` เป็นเวอร์ชัน offline (localStorage อย่างเดียว ไม่ต่อ Supabase)

## ⚠️ ความปลอดภัย (อ่านก่อน)
- ใช้ **publishable key** ฝังในหน้าเว็บ + RLS แบบเปิด (anon อ่าน/เขียนได้) → ใครมีลิงก์/คีย์ก็เข้าถึงข้อมูลได้ ควรเก็บลิงก์ไว้เฉพาะในทีม หรือกันหน้าเว็บด้วยรหัสผ่าน
- แนวทางที่ปลอดภัยกว่า: เปิด **Supabase Auth** (แต่ละคนล็อกอินด้วยบัญชีตัวเอง) + RLS แบบ `authenticated`
- ล็อกอินในแอปยังเทียบรหัส plain text (`1234`) — ควรเปลี่ยนไปใช้ auth จริงในภายหลัง
