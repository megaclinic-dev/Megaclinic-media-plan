# Media Plan · ตารางช่องทาง

ระบบวางแผนงานคอนเทนต์สำหรับทีมครีเอทีฟของคลินิกความงาม — ล็อกอินรายบุคคล, สิทธิ์ตามตำแหน่ง,
ตารางแผนงาน (ช่องทาง × วัน), ปฏิทินคอนเทนต์, หน้าสรุป, ตั้งค่ามาสเตอร์ดาต้า,
ประวัติการแก้ไข และ export Excel / CSV / JSON — UI ภาษาไทยทั้งหมด

## เปิดใช้งาน
เป็นเว็บ static ล้วน เปิดได้เลยโดยไม่ต้อง build:

- เปิดไฟล์ `index.html` ผ่าน static server (หรือ deploy โฟลเดอร์นี้ทั้งก้อน)
- ล็อกอิน: เลือกผู้ใช้คนแรก รหัสผ่านเริ่มต้น `1234` (เปลี่ยนได้ที่เมนู "ทีมงาน")

`media-plan.artifact.html` = เวอร์ชันไฟล์เดียว (bundle React + โค้ดทั้งหมดไว้ในไฟล์เดียว) เปิดได้ทันทีแบบ offline

## Deploy
- **GitHub Pages** — เปิด Settings → Pages → Deploy from branch: `main` / root แล้วเว็บจะขึ้นที่ `https://<user>.github.io/<repo>/`
- **Netlify** — มี `netlify.toml` (publish = `.`) พร้อม deploy ได้เลย

## หมายเหตุ (สำคัญก่อนใช้งานจริง)
เวอร์ชันนี้เป็น **โปรโตไทป์** ที่ทำงานได้เต็มระบบ แต่:
- เก็บข้อมูลใน `localStorage` ของแต่ละเบราว์เซอร์ — ยังไม่มีฐานข้อมูลกลาง (คนละเครื่องไม่เห็นข้อมูลกัน)
- รหัสผ่านเป็น plain text
- ใช้ design-tool runtime (`support.js`) โหลด React ในตัว

การใช้งานจริงกับทีมควรต่อ backend จริง (เช่น Postgres/Supabase) + auth จริง (hash + session/JWT)
และบังคับสิทธิ์ที่ฝั่ง API
